# Day 02 — Linux Text Processing

## Цель дня

Научиться работать с текстовыми файлами в Linux, освоить поиск, фильтрацию,
сортировку и обработку данных, изучить перенаправление потоков ввода-вывода
и использование конвейеров команд.

## Изученные темы

### 1. Просмотр текстовых файлов

Практика с командами:

    cat
    cat -n
    cat -b
    cat -A
    less
    head
    tail
    tail -n
    tail -f
    tail -F

### 2. Подсчёт строк, слов и символов

Изучена команда wc.

Практика:

    wc
    wc -l
    wc -w
    wc -c
    wc -m

### 3. Поиск текста

Изучена команда grep.

Практика:

    grep
    grep -i
    grep -n
    grep -c
    grep -v
    grep -E
    grep -o

Основы регулярных выражений:

    ^ — начало строки.
    . — любой одиночный символ.
    .* — произвольная последовательность символов.
    | — логическое ИЛИ в расширенных регулярных выражениях.

### 4. Сортировка и удаление повторений

Изучены команды:

    sort
    sort -k
    uniq
    uniq -c

Практика сортировки данных и подсчёта повторяющихся записей.

### 5. Извлечение и преобразование текста

Изучены команды:

    cut
    cut -d
    cut -f
    tr
    tr -d

### 6. Перенаправление ввода-вывода

Изучены стандартные потоки:

    stdin — стандартный ввод.
    stdout — стандартный вывод.
    stderr — стандартный поток ошибок.

Практика:

    > — перезапись файла.
    >> — добавление данных в конец файла.
    2> — перенаправление ошибок.
    tee — вывод результата на экран и запись в файл.
    tee -a — добавление результата в конец файла.

### 7. Конвейеры команд

Изучено использование оператора | для передачи вывода одной команды на вход другой.

Практика объединения команд:

    grep
    sort
    uniq
    awk

### 8. Основы обработки данных с AWK

Изучена команда awk.

Практика:

    $1 — обращение к первому полю строки.
    sum += $1 — накопление суммы значений.
    END — выполнение команды после обработки всех строк.
