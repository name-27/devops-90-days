# Day 09 — Linux Package Management

## Цель дня

Изучить управление пакетами в Debian-based Linux: работу с APT и dpkg, установку и удаление программ, зависимости пакетов и конфигурационные файлы.

Дополнительно закрепить навыки обработки JSON с помощью `jq`.

## Изученные темы

### 1. APT и управление пакетами

- Назначение APT и его роль в управлении пакетами.
- Обновление списка доступных пакетов с помощью `apt update`.
- Просмотр информации о пакетах через `apt show`.
- Поиск пакетов с помощью `apt search`.
- Просмотр доступных версий и источников пакетов через `apt-cache policy`.
- Разница между обновлением списка пакетов и обновлением установленных программ.

### 2. Установка и удаление пакетов

- Установка пакетов через `apt install`.
- Удаление пакета с помощью `apt remove`.
- Полное удаление пакета и его конфигурационных файлов через `apt purge`.
- Удаление автоматически установленных и больше не нужных зависимостей с помощью `apt autoremove`.
- Проверка предполагаемых действий APT без их выполнения через `--simulate`.
- Разница между удалением программы и удалением её конфигурационных файлов.

### 3. dpkg и локальные DEB-пакеты

- Назначение низкоуровневого менеджера пакетов `dpkg`.
- Проверка состояния установленного пакета через `dpkg -s`.
- Просмотр файлов, установленных пакетом, с помощью `dpkg -L`.
- Просмотр информации о локальном `.deb`-пакете через `dpkg -I`.
- Разница между `dpkg -i` и `apt install ./package.deb`.
- Различия между APT и dpkg при установке пакетов и разрешении зависимостей.

### 4. Зависимости пакетов

- Просмотр зависимостей пакета через `apt-cache depends`.
- Просмотр обратных зависимостей через `apt-cache rdepends`.
- Разница между зависимостями пакета и пакетами, которые от него зависят.
- Понимание того, почему удаление одной программы не обязательно приводит к удалению её зависимостей.

### 5. Конфигурационные файлы пакетов

- Просмотр информации о пакете через `dpkg-query -s`.
- Изучение секции `Conffiles`.
- Понимание того, как dpkg отслеживает конфигурационные файлы пакетов.
- Разница между `apt remove` и `apt purge`.
- Разница между конфигурационными файлами пакета и его зависимостями.

### 6. Дополнительная практика: работа с JSON через jq

- Установка и проверка `jq`.
- Получение значений из JSON-объектов.
- Обращение к вложенным полям.
- Извлечение элементов массивов.
- Фильтрация объектов с помощью `select()`.
- Использование конвейера `|` для последовательной обработки данных.
- Подсчёт количества элементов и длины строк.
- Формирование вывода с нужными полями.

## Практическая работа

### 1. Исследование пакетов

- Изучена информация о пакете `nginx` с помощью `apt show`.

- Разобрана связь между удалением пакета, его зависимостями и конфигурационными файлами.

- Выполнена симуляция `apt autoremove --simulate`.
- Проверено, что APT не предлагает удалить дополнительные пакеты.
- Фактическое удаление `jq` не выполнялось.

### 4. Практика с jq
