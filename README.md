# DevOps — 90 Days

## Цель проекта

Практическое обучение DevOps с нуля.
Цель — сформировать фундаментальные навыки, создать портфолио
практических проектов и подготовиться к собеседованиям на Junior DevOps.

## Формат обучения

- Продолжительность: 90 дней
- Нагрузка: 4–5 часов в день
- График: 6 учебных дней в неделю
- Основной подход: теория, практика, проверка результатов и документация

## Практические проекты

В процессе обучения будут созданы и задокументированы практические проекты,
включающие разработку приложения, контейнеризацию, автоматизацию сборки
и развёртывания, инфраструктуру и мониторинг.
