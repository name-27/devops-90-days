# Day 04 — Linux Permissions, Users and Groups

## Цель дня

Изучить систему прав доступа Linux, научиться управлять владельцами, группами и пользователями, настраивать совместный доступ к каталогам и файлам.

## Изученные темы

### 1. Права доступа Linux

- Права `r` (чтение), `w` (запись), `x` (выполнение).
- Права владельца, группы и остальных пользователей.
- Просмотр прав с помощью `ls -l`, `ls -la`, `ls -ld`.
- Подробная информация о файлах и каталогах с помощью `stat`.

### 2. Изменение прав доступа

- Команда `chmod`.
- Символьный формат: `u`, `g`, `o`, `a`.
- Операторы `+`, `-`, `=`.
- Числовой формат прав: `600`, `640`, `700`, `750`, `770`, `775`.
- Различия между правами доступа к файлам и каталогам.

### 3. Владельцы и группы

- `chown` — изменение владельца и группы.
- `chgrp` — изменение группы.
- `id` — информация о пользователе и группах.
- `groups` — список групп пользователя.
- `whoami` — текущий пользователь.
- `getent` — получение информации о пользователях и группах.

### 4. Управление пользователями и группами

- `useradd` — создание пользователей.
- `groupadd` — создание групп.
- `usermod` — изменение параметров пользователя.
- Добавление пользователей в дополнительные группы.
- Основные сведения о пользователях и группах в Linux.

### 5. Специальные права и маска доступа

- `setgid` — наследование группы каталогом.
- `umask` — маска прав доступа при создании файлов и каталогов.
- Взаимодействие `setgid` и `umask`.
- Проверка наследования группы и прав доступа.

### 6. Выполнение команд от имени другого пользователя

- Использование `sudo`.
- Выполнение команд от имени другого пользователя с помощью `sudo -u`.
- Проверка доступа к файлам и каталогам от имени разных пользователей.

## Практическая лабораторная работа

Создана группа `devops-lab` и пользователь `devops-test` для практики управления пользователями и совместного доступа.

Настроен общий каталог `shared`:

- Назначена группа `devops-lab`.
- Установлены права `2770`.
- Настроено наследование группы с помощью `setgid`.
- Проверено создание и изменение файлов от имени разных пользователей.
- Проверена работа `umask` со значениями `002` и `077`.
- Проверено ограничение доступа для посторонних пользователей.

## Результаты

- Созданы пользователь `devops-test` и группа `devops-lab`.
- Настроено управление владельцами и группами файлов.
- Настроен общий каталог `shared` с правами `2770`.
- Проверено наследование группы `devops-lab` при создании новых файлов.
