# Day 03 — Bash Fundamentals

## Цель дня

Изучить основы Bash scripting, научиться создавать скрипты для автоматизации задач, работать с переменными, условиями, циклами, функциями и аргументами командной строки.

## Изученные темы

### 1. Основы Bash scripting

- Создание и запуск Bash-скриптов.
- Shebang (`#!/bin/bash`).
- Права на выполнение (`chmod +x`).
- Переменные и переменные окружения.
- Пользовательский ввод (`read`, `read -p`).
- Подстановка команд `$(...)`.

### 2. Условия, циклы и функции

- Условные конструкции `if`, `else`, `case`.
- Операторы сравнения и проверки файлов.
- Циклы `for` и `while`.
- Создание и вызов функций.
- Передача аргументов в функции.
- Коды завершения `exit`, `return`, `$?`.

### 3. Аргументы и обработка ошибок

- Аргументы командной строки (`$0`, `$1`, `$2`, `$#`, `$@`).
- Проверка количества аргументов.
- Обработка ошибок и проверка результатов выполнения команд.

### 4. Перенаправление и обработка данных

- Стандартные потоки `stdin`, `stdout`, `stderr`.
- Перенаправление вывода и ошибок (`>`, `>>`, `2>`, `2>>`).
- Конвейеры команд (`|`).
- Обработка текста с помощью `grep`, `sort`, `uniq`, `cut`, `awk`.
- Просмотр и анализ логов с помощью `head`, `tail`, `wc`.

### 5. Автоматизация задач

- Работа с каталогами и файлами.
- Чтение данных из текстовых файлов.
- Создание резервных копий с помощью `tar`.
- Формирование отчётов на основе лог-файлов.

## Практическая лабораторная работа

Создан набор из 23 Bash-скриптов для изучения и практики автоматизации:

- Скрипты для работы с переменными, пользовательским вводом и аргументами.
- Скрипты с условиями, циклами и функциями.
- Скрипты для проверки файлов, каталогов и сервисов.
- Скрипт `backup.sh` для создания резервных копий каталогов.
- Скрипт `log_analyzer.sh` для анализа лог-файлов и формирования отчётов.

Подготовлены тестовые файлы, списки сервисов и пользователей, а также журналы для практики обработки данных.

## Результаты

- Созданы и проверены 23 Bash-скрипта.
- Освоены основные конструкции Bash и обработка ошибок.
- Реализовано резервное копирование с созданием архивов `.tar.gz`.
- Реализован анализ логов с подсчётом ошибок, предупреждений и информационных сообщений.
- Проверено создание, чтение и восстановление резервных копий.
- Проверена обработка некорректных аргументов и отсутствующих файлов и каталогов.
- Проверена структура проекта и устранены ошибки в скриптах.
