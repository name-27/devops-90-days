# Day 01 — Linux Fundamentals

## Цель дня

Изучить основы файловой системы Linux, научиться работать с файлами
и каталогами, управлять правами доступа, владельцами и группами.

## Изученные темы

### 1. Файловая система Linux

Изучены основные каталоги:

- `/` — корень файловой системы.
- `/home` — домашние каталоги пользователей.
- `/root` — домашний каталог суперпользователя.
- `/etc` — системные конфигурации.
- `/var` — изменяемые данные и журналы.
- `/tmp` — временные файлы.
- `/usr` — программы и пользовательские ресурсы.
- `/opt` — дополнительное программное обеспечение.
- `/dev` — файлы устройств.
- `/proc` — информация о процессах и ядре.
- `/boot` — файлы загрузки.

### 2. Информация о системе

Практика с командами:

- `pwd`
- `whoami`
- `id`
- `uname -a`
- `cat /etc/os-release`
- `df -h`
- `free -h`

### 3. Навигация

- `cd`
- `cd ~`
- `cd ..`
- `cd -`
- `cd /`
- Абсолютные и относительные пути.
- Использование `.` и `..`.

### 4. Просмотр каталогов

- `ls`
- `ls -l`
- `ls -a`
- `ls -h`
- `ls -lah`

### 5. Работа с файлами и каталогами

- `mkdir -p`
- `touch`
- `cp -r`
- `cp -v`
- `mv -v`
- `rm -i`
- `rm -r`
- `rmdir`
- `file`
- `stat`
- `find`

### 6. Права доступа

Изучены права `r` (чтение), `w` (запись), `x` (выполнение),
а также права владельца, группы и остальных пользователей.

Практика с `chmod`:

- `600` — `rw-------`
- `640` — `rw-r-----`
- `644` — `rw-r--r--`
- `664` — `rw-rw-r--`
- `700` — `rwx------`
- `750` — `rwxr-x---`
- `755` — `rwxr-xr-x`

### 7. Владельцы и группы

- `chown` — изменение владельца.
- `chgrp` — изменение группы.
- `id` — информация о пользователе и группах.
- `groups` — список групп пользователя.
- `sudo` — выполнение команды с повышенными привилегиями.

### 8. Маска создания прав доступа

Изучена команда `umask`.

Практика:

- `umask 022` — файлы `644`, каталоги `755`.
- `umask 027` — файлы `640`, каталоги `750`.
- Проверка через `umask` и `umask -S`.
