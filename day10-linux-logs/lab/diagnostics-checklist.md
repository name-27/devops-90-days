# Linux Diagnostics Checklist

## 1. Состояние systemd

- `systemctl --failed` — службы в состоянии failed.
- `systemctl status SERVICE` — состояние конкретной службы.
- `journalctl -u SERVICE -n 20` — последние записи службы.

## 2. Системные журналы

- `journalctl -p err -b` — ошибки текущей загрузки.
- `journalctl -p warning -b` — предупреждения текущей загрузки.
- `journalctl --list-boots` — список сохранённых загрузок.

## 3. Сообщения ядра

- `dmesg -T | tail -n 20` — последние сообщения ядра с календарными метками времени.
- `journalctl -k -n 20` — последние записи ядра в journald.
- `journalctl -k -p warning -b` — предупреждения ядра за текущую загрузку.

## 4. Файловые журналы

- `ls -lah /var/log` — просмотр содержимого каталога журналов.
- `tail -n 20 /var/log/dpkg.log` — последние записи журнала dpkg.
- `cat /var/log/apt/history.log` — история операций APT.
- `tail -n 30 /var/log/apt/term.log` — последние строки терминального журнала APT.

## 5. Ротация журналов

- `cat /etc/logrotate.conf` — глобальная конфигурация logrotate.
- `ls -lah /etc/logrotate.d` — дополнительные конфигурации.
- `logrotate -d /etc/logrotate.conf` — проверка конфигурации без внесения изменений.
- `systemctl status logrotate.timer` — состояние таймера.
- `systemctl status logrotate.service` — состояние службы ротации.

## 6. Принципы диагностики

- Проверять не только сообщение, но и его источник.
- Учитывать время появления и повторяемость события.
- Различать предупреждение, ошибку и фактический отказ.
- Не изменять системные настройки без понимания причины.
- После проверки фиксировать результат и вывод.
